# 🐍 Snake Survival Game

A fast-paced, mouse-controlled 2D canvas game built with vanilla JavaScript. Players navigate a snake around the board, collect apples to score points, and dodge moving bombs across progressively challenging levels.

## ✨ Features
* **Mouse Navigation:** Smooth, fluid snake movement following user cursor input.
* **Dynamic Difficulty:** Level-based progression that increases challenge over time with moving bombs.
* **Persistent Scoring:** LocalStorage integration to save and track high scores across sessions.
* **Clean UI & Controls:** Responsive design with instant restart capabilities.

## 🛠️ Built With
* **JavaScript (ES6+)** - Core gameplay logic, collision detection algorithms, state management, and score tracking.
* **HTML5 Canvas** - Dynamic 2D rendering and animations.
* **CSS3** - Layout styling and responsive canvas alignment.
